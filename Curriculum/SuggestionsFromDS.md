下面以《计算机科学与技术专业本科培养方案 2025 级》和《工程物理专业本科培养方案》中的“工程物理专业”主方案为主比较；工程物理系文件还含“能源实验班”“核工程与核技术”，差异会在末尾略提。

## 一、总体差异

| 维度 | 计算机科学与技术（CS） | 工程物理（EP） |
|---|---|---|
| 培养目标 | 宽口径计算机专业教育，培养“学术大师/兴业之士”，强调计算理论、系统、软件、网络、AI与安全 | 工程与物理结合，面向能源、安全、健康、环境、物质科学等，核特色明显 |
| 总学分 | 148 | 170 |
| 通识教育 | 47 | 44 |
| 专业相关/专业教育 | 专业相关课程88 + 专业实践13 | 专业教育116 + 自主发展10 |
| 实践学分 | 13：夏季实习4 + 综合论文9 | 26：夏季实践11 + 综合论文15 |
| 学位/学制 | 工学学士，4年，最长6年 | 工学学士，4年，最长6年 |
| 课程重心 | 计算机核心课密集：数据结构、组成、OS、网络、编译、软工、AI、安全等 | 数理与工程基础厚：基础物理、近代物理实验、量子/统计/电动/流体/热工、电路电子工程力学、核专业核心 |
| 专业选修 | 12学分限选，按系统结构、软件理论、应用技术、专题训练四方向，每方向建议至少2学分 | 7学分，四个核/电子/加速器/反应堆课组中完整选一个课组 |
| 自主发展 | 未单列 | 10学分：自然科学2、学科基础5、专业任选3，可修外专业课程/研究生课/研究训练 |

## 二、课程结构差异

### 1. 数学与物理基础
- CS基础理论25学分：微积分A 10、线性代数4、概率3、大学物理两学期共8；另有复变、数值分析/数学实验、离散数学等专业基础。
- EP数学与自然科学39学分：数学19（微积分、线代、复变、数理方程），物理20（基础物理学三学期、基础物理实验）。EP物理明显更重，且后续有量子力学、统计力学、电动力学、流体力学、热工基础、信号与系统等。
- CS的数学更偏“离散、概率、数值、算法”；EP的数学物理更偏“连续、物理建模、方程与实验”。

### 2. 工程与计算机基础
- CS没有电路、电子技术、工程图学、工程力学等硬工程基础；计算机课程从程序设计、面向对象、数据结构、数字逻辑、计算机系统概论开始。
- EP工程技术基础14学分：工程图学、计算机程序设计基础、电路原理、电子技术/模电/数电/工程力学等；计算机类核心仅“计算机程序设计基础”3学分，另有工具软件、应用软件设计与实践、实验物理大数据、计算机模拟物理等可选。
- 因此：EP学生“会编程”但不等于“受过计算机专业训练”；CS学生“计算机系统完整”，但物理与工程实验训练少。

### 3. 专业核心
- CS专业核心51学分（57中修不少于51）：数据结构、计算机组成、操作系统、计算机网络、软件工程、编译原理、形式语言与自动机、计算机系统结构、AI导论、网络空间安全导论等，覆盖“理论—系统—软件—网络—应用”。
- EP专业核心15学分：工程物理概论、核辐射物理与探测、核工程原理、辐射防护、专业基础实验；学科基础另14学分。EP的专业核心是“核与工程物理”，不是计算机。

### 4. 实践与自主发展
- CS实践13学分，偏“程序设计训练+专业实践+论文”。
- EP实践26学分，含金工实习、电子工艺实习、生产实习、综合论文15学分，工程训练更重。
- EP有10学分自主发展课程，文件明确包含“外专业基础课程及专业主修课程、研究生层次课程、研究训练/创新创业”，这是EP学生补计算机知识最重要的学分空间。

## 三、能力与出口差异
- CS毕业生：具备计算系统、软件、网络、AI/安全等较完整知识，适合计算机学术研究、互联网/软件/系统/算法/安全/AI等。
- EP毕业生：数理基础、物理实验、工程实践和核领域知识强，适合能源、核工程、安全、健康、环境、物质科学、仪器探测、科研计算等。
- 两者都强调工程认证式能力：实验与数据分析、多学科团队、沟通、终身学习、工程工具、现实约束下的系统设计。但CS的“系统”是计算系统，EP的“系统”是工程物理/核系统。

## 四、工程物理系学生如何补充计算机知识

建议不要“照搬CS全培养方案”，而是以“计算科学/智能交叉/核工程仿真/数据分析”为目标，分层次补。EP数理基础很好，短板通常是离散数学、数据结构与算法、计算机系统、软件工程。

### 1. 最小补强包（建议优先）
1. **程序设计进阶**：面向对象程序设计基础；掌握C++或Python工程化编程，不只学语法。
2. **数据结构与算法**：CS的“数据结构”4学分，最重要；配合算法设计与分析。
3. **离散数学**：EP没有，补离散数学(1)(2)或至少离散数学基础。
4. **数据库系统概论**：科研数据、核数据管理、实验数据管理很实用。
5. **机器学习/人工智能导论**：若做AI4Science、探测数据分析、图像/信号处理。
6. **计算机系统课至少2门**：计算机组成原理、操作系统、计算机网络原理中选2；想深入系统就三门都补。

### 2. 按目标选课
- **科研计算/核工程仿真**：数值分析、高性能计算导论、计算机模拟物理、实验物理的大数据方法、数据库、C++/Python、Linux/Git、MPI/OpenMP/CUDA、Geant4/ROOT/OpenMC等工具。
- **AI/数据分析**：数据结构、离散数学、数据库、机器学习、数据挖掘、人工智能导论、PyTorch/NumPy/Pandas/Scikit-learn。
- **软件/系统开发**：数据结构、操作系统、计算机网络、数据库、软件工程、编译原理可选；重点做项目、版本控制、测试、调试。
- **探测/核电子学交叉**：信号与系统、核数据获取与处理、核数据获取与处理课程设计、嵌入式系统、计算机网络、数据库。

### 3. 学分如何嵌入EP方案
- 用**自主发展课程10学分**：文件允许选“外专业的基础课程及专业主修课程、研究生层次课程、研究训练/创新创业”。可放数据结构、离散数学、数据库、机器学习等。
- 用**专业任选课3—5学分**：能源班/核工程有专业任选5学分，可在全校专业课程中选；工程物理主方案专业任选3学分。
- 文件还说明“学科基础任选多选课程可计入专业选修课任选课中”，可提前规划避免浪费。
- 建议每学期只加1门计算机课，不要冲击量子力学、统计力学、电动力学、核辐射物理等EP核心。

### 4. 推荐路线图
- 大一下—大二上：程序设计进阶 + 数据结构；同时自学Linux/Git。
- 大二下：离散数学 + 数据库/数值分析。
- 大三上：计算机组成或操作系统 + 机器学习/人工智能导论。
- 大三下：计算机网络或高性能计算 + 一个交叉项目。
- 大四：SRT/生产实习/综合论文中用计算机方法做核数据、探测模拟、反应堆仿真或实验大数据。

### 5. 注意事项
- 先修顺序：程序设计→数据结构→数据库/算法；计算机组成→操作系统；概率统计→机器学习；数值分析→高性能计算。
- 不要只学“语言”。计算机专业核心价值在数据结构与算法、系统抽象、数据库、软件工程和项目实践。
- 选课前查教务先修要求和学分认定；若目标转向计算机学位，需考虑辅修/双学位或研究生阶段，单靠自主发展学分难以完全覆盖CS核心。
- 工程物理系文件含能源实验班、核工程与核技术方案，总学分同为170，但专业教育114、自主发展12，专业选修/方向课组不同；补计算机的学分空间类似，能源班专业任选5学分、核工程专业任选5学分，均可优先放数据结构、数据库、机器学习等。

**一句话总结**：CS是“计算机系统完整训练”，EP是“数理工程+核特色训练”；EP学生补计算机应以“数据结构与算法+离散数学+数据库+至少两门系统课+机器学习/高性能计算”为主线，利用自主发展10学分和专业任选学分嵌入，并结合核数据、实验大数据、计算物理等交叉项目落地。
